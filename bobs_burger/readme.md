This is a cute visualization of the Bob's Burger episode space in a Shiny for R app.

Notably, the supporting scripts that were used to get the data demonstrate the use of the `chromium` package to simulate an interactive browser session to scrape websites that are not directly readable.

The *agent* folder shows some of the instructions that were given to Claude Code to write most of the Shiny app.

Much of the data and the inspiration came from Steven Ponce's [`bobsburgersR`](https://github.com/poncest/bobsburgersR) package.
